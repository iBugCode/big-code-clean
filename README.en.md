# ✨ Code Clean

**A lightweight, pure frontend code cleaning tool**

Custom text & regex replacement schemes, stored locally in your browser. Zero setup.

<br/>

[![Deploy to Cloudflare Pages](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/iBugCode/Code-Clean)

<br/>

## 🎯 Features

| Feature | Description |
|:---:|:---|
| 📋 **Paste & Clean** | Paste code to auto-clean and select all |
| 🖱️ **Double-click Copy** | Double-click to copy cleaned result |
| 🔧 **Custom Schemes** | Text and regex replacement rules |
| 📝 **Multi-rule** | Combine multiple rules per scheme |
| 💾 **Local Storage** | Data stays in your browser, no sign-up |

## 🚀 Local Development

No build step. Open `index.html` directly in your browser.

```bash
# Or use any static server
npx serve .
```

## ☁️ Deploy to Cloudflare Pages

1. Fork this repo
2. Go to [Cloudflare Pages](https://pages.cloudflare.com), connect your GitHub repo
3. Build settings:
   - **Build command** → leave empty
   - **Build output directory** → `.`
   - **Framework preset** → `None`
4. Click **Deploy**
