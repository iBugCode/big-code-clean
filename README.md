# ✨ Code Clean

**轻量、纯前端的代码清洗工具**

自定义文本替换与正则替换方案，数据保存在本地浏览器，开箱即用。

<br/>

[![Deploy to Cloudflare Pages](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/iBugCode/Code-Clean)

<br/>

</div>

---

## 🎯 功能特性

| 功能 | 说明 |
|:---:|:---|
| 📋 **粘贴即清洗** | 粘贴代码自动清洗并全选 |
| 🖱️ **双击复制** | 双击输入区一键复制清洗结果 |
| 🔧 **自定义方案** | 支持文本替换与正则替换 |
| 📝 **多规则组合** | 每个方案可配置多条替换规则 |
| 💾 **本地存储** | 数据保存在 localStorage，无需登录 |

## 🚀 本地运行

无需构建，直接用浏览器打开 `index.html` 即可。

```bash
# 或使用任意静态服务器
npx serve .
```

## ☁️ 部署到 Cloudflare Pages

1. Fork 本仓库
2. 登录 [Cloudflare Pages](https://pages.cloudflare.com)，连接 GitHub 仓库
3. 构建设置：
   - **构建命令** → 留空
   - **构建输出目录** → `.`
   - **框架预设** → `None`
4. 点击 **部署**
